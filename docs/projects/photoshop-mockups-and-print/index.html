About the project

What I did

I added layer search and caching, reuse of open PSD mockups, three-image set handling and export based on a size table.

Outcome

The supplied code supports single and triptych mockups, PNG export and 11 print sizes configured at 300 dpi. The diagram explains the code; an execution recording is not included.
