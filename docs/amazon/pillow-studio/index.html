Questions about this collection

How can I compare the designs?

Use the design choices above or the 3D viewer below. The same model is used for each direction so differences in artwork and palette are easy to see.

Can I see the back of the pillow?

Yes. Drag the 3D model to rotate it, then zoom to inspect how the pattern continues over the surface.

Is this an available product?

No. STUDIO / SOFT and the three designs are portfolio concepts. The source 3D model is licensed CC0 by Poly Haven. No material, size, care or sales claims are made.
