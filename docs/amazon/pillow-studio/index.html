A few useful details

What creates the raised pattern?

Closely spaced rows of cord form the arches and semicircle, standing above the woven-look base.

How can I style it?

Start with a plain sofa or chair. Echo one cushion colour in a throw, rug or nearby object, and let the raised pattern remain the main accent.

Which colourway adds the most contrast?

Ink gives the strongest dark-to-light contrast. Oat stays light and neutral; Clay brings a warmer, tonal look.
