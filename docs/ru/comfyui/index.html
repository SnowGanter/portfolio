ЛОКАЛЬНЫЙ АГЕНТ ДЛЯ ДИЗАЙНА

Strata Agent

Агент, которого я создал для собственной дизайнерской работы. Он работает на домашнем ПК: открытый движок Strata запускает языковую модель Qwen3.8-Flash-Next, ComfyUI рисует и редактирует изображения, а Photoshop собирает многослойные PSD. Как агент для программирования, он планирует задачу, вызывает инструменты, сам проверяет каждый результат и исправляет ошибки.

  • Qwen3.8-Flash-NextMoE-модель на 125 млрд параметров, IQ2_XS, локально через Strata
  • Krea 2 · Flux3 Klein · Qwen Image 2.1генерация, локальные правки и вырезание в ComfyUI
  • Photoshop · Topazмногослойные PSD со смарт-объектами и апскейл для печати
  • ~5 минзанимает переключение видеокарты между языковой моделью и ComfyUI, поэтому агент группирует работу с изображениями

ЛОКАЛЬНЫЙ ВЕКТОРИЗАТОР

От растра к чистому SVG

Моя собственная нода для ComfyUI — My Vectorizer — в режиме «shapes» собирает SVG так, как это сделал бы иллюстратор: каждая цветовая область становится отдельной залитой фигурой, крупные заливки лежат внизу, мелкие детали и тонкие линии — сверху. Контуры строит potrace по растру, увеличенному вдвое, поэтому край проходит по середине сглаживания без ступенек. Изображение на 1–2 Мп обрабатывается примерно за 15–30 секунд.

  1. LoadImage
  2. RealESRGAN ×4 · 2 MP
  3. Palette
  4. potrace ×2
  5. Stack
  6. SVG
SVG

Входные файлы: мои тестовые иллюстрации, созданные ИИ, 1448 × 1086 px. Результаты — два SVG, сохранённые нодой.

ПАНЕЛЬ ДЛЯ PHOTOSHOP

ComfyFloatBar

Плавающая панель (Electron), которая соединяет Photoshop с локальными процессами ComfyUI: берёт выделение или активный слой, отправляет его в выбранный процесс и возвращает результат новым слоем. Ниже — рабочая копия интерфейса: открывайте разделы, переключайте режимы, двигайте ползунки и нажимайте главные кнопки. Вместо генерации в браузере демо вставляет заранее подготовленные результаты из моих проектов.
