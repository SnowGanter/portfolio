Серия кампании

Шесть креативов: основной макет выше, три новые фотосцены, типографический плакат и фотокомпозиция. Разные сообщения в едином визуальном стиле.

Задача

Создать рекламу путешествий, которая приглашает к спонтанным открытиям. Передать сообщение через пейзаж, а не туристическое предложение.

Визуальное направление
