Photoshop Scripts · Построение процесса и разработка скрипта

Пакетные мокапы и экспорт для печати

Скрипт Photoshop для размещения дизайнов в мокапах и экспорта в нескольких размерах для печати.

Задача

Заменять дизайн в смарт-объектах и экспортировать отдельные картины и триптихи без повторения каждого шага вручную.

Построение процесса и разработка скрипта

Схема процесса · по предоставленному коду, не видеозапись

ПРОЕКТ

О проекте

Что было сделано

Добавил поиск и кеширование слоёв, повторное использование открытых PSD-мокапов, обработку наборов из трёх изображений и экспорт по таблице размеров.

Результат

В предоставленном коде предусмотрены одиночные мокапы и триптихи, экспорт PNG и 11 размеров для печати с настройкой 300 dpi. Схема объясняет код; запись запуска не добавлена.
