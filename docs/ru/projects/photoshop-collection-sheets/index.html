Photoshop Scripts · Построение процесса и разработка скрипта

Каталог из 100 дизайнов

Скрипт Photoshop, который заполняет многокадровый PSD-шаблон и экспортирует пронумерованные листы коллекции.

Задача

Разместить коллекцию из 100 изображений в смарт-объектах шаблона и экспортировать листы партиями.

Построение процесса и разработка скрипта

PsPHOTOSHOP SCRIPT
  1. 01100 исходных изображений
  2. 02Поиск смарт-объектов
  3. 03Заполнение PSD-шаблона
  4. 04Пронумерованные PNG-листы

Схема процесса · по предоставленному коду, не видеозапись

ПРОЕКТ

О проекте

Что было сделано

Добавил поиск папок с исходниками, сбор смарт-объектов, подгонку изображений и пакетное сохранение. Экспортированные листы не учитываются как исходные изображения.

Результат

Код экспортирует пронумерованные PNG-листы и заполняет последний неполный лист без повторов изображений внутри него. Схема построена по скрипту; это не запись запуска.
