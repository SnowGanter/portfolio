Photoshop Scripts · Разработка Photoshop-скрипта

Коллекция из 100 дизайнов — в мокапах

Автозаполнение многокадрового PSD-шаблона партиями.

Задача

Разложить коллекцию изображений по смарт-объектам шаблона и сохранить последовательность сводных листов.

Разработка Photoshop-скрипта

PsPHOTOSHOP SCRIPT
  1. 01Коллекция из 100 изображений
  2. 02Подготовка смарт-объектов
  3. 03Заполнение шаблона партиями
  4. 04Сводные PNG-листы

Схема по исходному коду · не видеозапись

ПРОЕКТ

Решение и результат

Что было сделано

Добавил поиск папок со 100 исходными изображениями, сбор смарт-объектов, подготовку содержимого под их размеры и пакетное сохранение. Результаты экспорта исключаются из подсчёта исходников.

Результат

Предусмотрен экспорт пронумерованных PNG-листов. В неполной последней партии свободные места заполняются изображениями без повторов в текущем листе. Показана схема по коду, не видеозапись.
