Добавил поиск папок с исходниками, сбор смарт-объектов, подгонку изображений и пакетное сохранение. Экспортированные листы не учитываются как исходные изображения.

Код экспортирует пронумерованные PNG-листы и заполняет последний неполный лист без повторов изображений внутри него. Схема построена по скрипту; это не запись запуска.
