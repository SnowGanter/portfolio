Схема по исходному коду · не видеозапись

Добавил поиск папок со 100 исходными изображениями, сбор смарт-объектов, подготовку содержимого под их размеры и пакетное сохранение. Результаты экспорта исключаются из подсчёта исходников.

Предусмотрен экспорт пронумерованных PNG-листов. В неполной последней партии свободные места заполняются изображениями без повторов в текущем листе. Показана схема по коду, не видеозапись.
