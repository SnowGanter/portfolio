LOCAL DESIGN AGENT

Strata Agent

An agent I built for my own design work. It runs on a home PC: the open-source Strata engine serves the Qwen3.8-Flash-Next language model, ComfyUI draws and edits images, and Photoshop assembles layered PSD files. Like a coding agent, it plans the task, calls tools, checks every result itself and fixes what is wrong.

  • Qwen3.8-Flash-Nexta 125-billion-parameter MoE model, IQ2_XS, run locally through Strata
  • Krea 2 · Flux3 Klein · Qwen Image 2.1generation, local fixes and cut-outs in ComfyUI
  • Photoshop · Topazlayered PSD files with smart objects and print upscaling
  • ~5 minto swap the GPU between the language model and ComfyUI, so the agent batches image work

LOCAL VECTORISER

From raster to clean SVG

My custom ComfyUI node, My Vectorizer, builds an SVG in the “shapes” mode the way an illustrator would: every colour area becomes a separate filled shape, large fills sit at the bottom, small details and thin lines on top. Contours are traced by potrace on a raster enlarged 2×, so edges run through the middle of the anti-aliasing without stair-steps. A 1–2 MP image takes about 15–30 seconds.

  1. LoadImage
  2. RealESRGAN ×4 · 2 MP
  3. Palette
  4. potrace ×2
  5. Stack
  6. SVG
SVG

Inputs: my AI-generated test illustrations, 1448 × 1086 px. Outputs: the two SVG files saved by the node.

PHOTOSHOP PANEL

ComfyFloatBar

A floating desktop panel (Electron) that connects Photoshop to local ComfyUI workflows: it takes the selection or the active layer, sends it to the chosen workflow and places the result back as a new layer. Below is a working replica of the interface: open sections, switch modes, move sliders and press the main buttons. Instead of running generation in the browser, the demo inserts prepared results from my projects.
