Запитання про колекцію

Як порівняти дизайни?

Скористайтеся вибором дизайну вгорі або 3D-переглядом нижче. Для кожного напряму використана та сама модель, тож легко порівняти композицію й палітру.

Чи можна побачити зворотну сторону подушки?

Так. Перетягніть 3D-модель, щоб повернути її, та наблизьте для перегляду візерунка на поверхні.
