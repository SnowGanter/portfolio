ЛОКАЛЬНИЙ АГЕНТ ДЛЯ ДИЗАЙНУ

Strata Agent

Агент, якого я створив для власної дизайнерської роботи. Він працює на домашньому ПК: відкритий рушій Strata запускає мовну модель Qwen3.8-Flash-Next, ComfyUI малює й редагує зображення, а Photoshop збирає багатошарові PSD. Як агент для програмування, він планує задачу, викликає інструменти, сам перевіряє кожен результат і виправляє помилки.

  • Qwen3.8-Flash-NextMoE-модель на 125 млрд параметрів, IQ2_XS, локально через Strata
  • Krea 2 · Flux3 Klein · Qwen Image 2.1генерація, локальні правки й вирізання в ComfyUI
  • Photoshop · Topazбагатошарові PSD зі смарт-об’єктами й апскейл для друку
  • ~5 хвтриває перемикання відеокарти між мовною моделлю й ComfyUI, тому агент групує роботу із зображеннями

ЛОКАЛЬНИЙ ВЕКТОРИЗАТОР

Від растра до чистого SVG

Моя власна нода для ComfyUI — My Vectorizer — у режимі «shapes» збирає SVG так, як це зробив би ілюстратор: кожна кольорова область стає окремою залитою фігурою, великі заливки лежать унизу, дрібні деталі й тонкі лінії — згори. Контури будує potrace за растром, збільшеним удвічі, тож край проходить серединою згладжування без сходинок. Зображення на 1–2 Мп обробляється приблизно за 15–30 секунд.

ПАНЕЛЬ ДЛЯ PHOTOSHOP

ComfyFloatBar

Плаваюча панель (Electron), що з’єднує Photoshop із локальними процесами ComfyUI: бере виділення або активний шар, надсилає його в обраний процес і повертає результат новим шаром. Нижче — робоча копія інтерфейсу: відкривайте розділи, перемикайте режими, рухайте повзунки й натискайте головні кнопки. Замість генерації в браузері демо вставляє заздалегідь підготовлені результати з моїх проєктів.
